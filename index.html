Side project · Valorant heatmap · 2026

Sightline

An interactive heatmap of where Valorant players stand, die and get kills, built from 1,358 ranked matches.

Why

When I peek a site, where is the enemy most likely to be? I wanted real match data instead of gut feel.

How it works

  • Pulls ranked match data from the HenrikDev API
  • Python maps every player's position onto the minimap and turns it into heatmaps
  • Filter by map, rank, side, agent and round phase
